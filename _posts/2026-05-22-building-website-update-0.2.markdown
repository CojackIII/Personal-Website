I spent a good amount of time watching the tutorials that Giraffe Academy has uploaded 8 years ago and they are still very helpful and relevant! Not much has changed in all these years which makes it very easy to pick up given such woderfully crafted tutorials.

That being said, I have a much better understanding of how everything is laid out and what I can possibly do with this website (the sky truly is the limit here). Watching the tutorials has given me a lot of confidence, hope, and inspiration to not only continue this project for the long run, but to not be afraid to try something that maybe other people haven't considered! I'm not sure what that is yet, but I know when I get to the point where I'm stepping into untreaded territory, that I have good documentation and community to fall back on!

As far as what I've actually done to my website today... not much. I connected my local Jekyll project space with my GitHub repo so that this website is live! For the rest of today and liekly tomorrow, I'm going to be physically drawing out what I want the website to look like, what features, and what content I want to display so that I have a clear goal when I start implementing it. For now, I'm going to keep scope very well in mind and not really play with the colors and setup too much. Off the top of my head, I really just want a cover page, a dropdown page selector, and a gallery for my portfolio. Other ideas will likely spring out at me, but seeing as this page is live on GitHub, I'm going to focus on functionality over looks for now. After all, it's fairly simple to just change the color (although I want to do something special regarding the color scheme :D).

The only issue that I'm coming across right now is the interconnectivity of the twitter icon front matter... I want to change it to discord as I don't have a very big social media presence at the moment. Nothing too hard I don't think, but it might be a tedious process as I can't just refactor the variable in the yaml config.

Regardless, although there wasn't too much actual changes to my workspace, I learned a lot about how this website system works and I'm looking forward to how this all comes together!
