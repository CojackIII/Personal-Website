This is my first post to my personal website! There's much work to be done and I have a lot of fun ideas to really make the website *mine*. So far the website is still very barebones and probably 90% of it is still the default template theme that Jekyll gives you when you make your first project, but I did rewrite the About page and fiddled around with some of the defaults and things with minimal outside help simply to gather my bearings and familiarize myself with how the Jekyll webpage builder organizes things.

That said, tomorrow I'm going to watch the community tutorials that are posted on the Jekyll website to gain a verbal explantation of what it is that I was messing with, the features, and how I can use them to "upgrade" this website. I'm very excited to continue this project and I'm sure that this is going to be a lifelong project that I keep up with as time goes on!

As for what I actually did today, it was mainly *only* rewriting the content of the About page and this post. I didn't even create a new post for this I just commented the defaults out so that I can look back at it in case I need a reminder of what I can do in the posts:
